# Portafolio de Camilo Díaz

Portafolio estático creado con HTML, CSS y JavaScript.

## Contenido
- `index.html`: secciones, proyectos y enlaces.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: navegación móvil y efectos.
- `images/`: mockups conceptuales para las tarjetas de proyectos.

## Proyectos
- PostureLab: https://github.com/Cami-ng23/PostureLab_Proyecto2 — demo: https://posturelab-proyecto2.onrender.com/
- MiMetodo: https://github.com/Cami-ng23/MiMetodo — demo: https://mimetodo.onrender.com/
- AcademyMap: https://github.com/Cami-ng23/AcademyMap — demo: https://academymap-8s8i.onrender.com

## Importante sobre las imágenes
Las imágenes incluidas son mockups conceptuales creados para la presentación visual. No son capturas reales de las aplicaciones ni garantizan que la interfaz publicada sea idéntica. Los enlaces de GitHub y las demos permiten visitar los proyectos reales.

## Ver el portafolio
Abre `index.html` en el navegador. No requiere instalación.
