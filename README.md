# Portafolio Camilo Díaz

Portafolio estático creado con HTML, CSS y JavaScript.

## Proyectos
- PostureLab: https://github.com/Cami-ng23/PostureLab_Proyecto2 — demo: https://posturelab-proyecto2.onrender.com/
- MiMetodo: https://github.com/Cami-ng23/MiMetodo — demo: https://mimetodo.onrender.com/
- AcademyMap: https://github.com/Cami-ng23/AcademyMap — demo: https://academymap-8s8i.onrender.com

## Estructura
- `index.html`: contenido y estructura (sin frameworks).
- `styles.css`: estilos organizados por secciones (tokens, cabecera, hero, proyectos, contacto, responsivo, movimiento reducido).
- `script.js`: interacciones sin dependencias (progreso de scroll, aparición de secciones, luz del cursor, inclinación 3D, marcador animado, menú móvil).
- `images/`: mockups de los proyectos.

## Notas de diseño
- Paleta: crema `#f4efe6`, oscuro `#201d1a`, coral `#f2614a`, verde lima `#d8f36b`, lila `#c7b6ec`.
- Las animaciones respetan `prefers-reduced-motion` y los efectos de cursor solo se activan con mouse.
